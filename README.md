
# Каталог книг

Учебный проект на Django.

## Возможности

- Добавление информации о книгах через HTML-форму.
- Сохранение книг в JSON и XML.
- Загрузка JSON/XML-файлов на сервер.
- Проверка корректности введённых данных.
- Удаление некорректных загруженных файлов.
- Отображение всех сохранённых книг на сайте.

## Технологии

- Python
- Django
- HTML
- CSS
- JSON
- XML

## Установка и запуск

1. Клонировать репозиторий.
2. Создать и активировать виртуальное окружение.
3. Установить зависимости:

   pip install -r requirements.txt

4. Выполнить миграции:

   python manage.py migrate

5. Запустить сервер:

   python manage.py runserver

6. Открыть в браузере:

   http://127.0.0.1:8000/

## Структура данных

Каждая книга содержит:

- title — название книги;
- author — автор;
- year — год издания;
- pages — количество страниц.

Файлы сохраняются в папку media/books.

Для хранения информации о книгах база данных
не используется.
